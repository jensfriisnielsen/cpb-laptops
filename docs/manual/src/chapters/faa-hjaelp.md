# Få hjælp

Hvis noget ikke virker, så prøv i denne rækkefølge:

1. **Slå det op i manualen.** Du læser den lige nu — du kan altid finde den igen under
   bogmærket **Laptop-manual** eller på `http://localhost:8888`.
2. **Tænk: er det noget, jeg selv kan fikse?** Luk og åbn programmet igen (Alt+F4).
   Tjek netværket (kapitlet [Hurtig start](hurtig-start.md)). Tag et USB-kabel ud og i
   igen (kapitlet [LEGO SPIKE og micro:bit](spike-og-microbit.md)).
3. **Spørg din lærer** — eller en anden voksen med **admin**-adgangskoden.

## Almindelige problemer

| Problem | Løsning |
| --- | --- |
| Ingen internet | Tjek at **BAL-Internet** er forbundet (netværksikonet). Virker det ikke, så slå Wi-Fi fra og til igen. |
| koderup.dk virker ikke | Kræver internet + Netbird. Se kapitlet [koderup.dk og hjemmesiden](koderup-dk.md). |
| YouTube åbner ikke | Det er meningen — YouTube er blokeret i de styrede browsere. |
| Intet billede på skærmen | Prøv at tænde skærmen med funktionstasterne (fx **F7**) eller spørg din lærer. |
| Ingen lyd fra højttalerne | De indbyggede højttalere er slået fra på klassecomputere. Brug hovedtelefoner (3,5 mm), USB/Bluetooth-headset eller HDMI-lyd. |
| Programmet hænger | Luk det helt (Alt+F4) og åbn det igen. |

## Pas på din laptop

- **Ingen mad og drikke** ved computeren.
- Bær den i tasken og løft den i bunden — ikke i skærmen.
- Sig altid til din lærer, hvis du taber den eller hører en mærkelig lyd.

## Ordliste

| Ord | Betydning |
| --- | --- |
| **Browser** | Program til at kigge på sider på internettet (fx Firefox eller Brave). |
| **Bogmærke** | Gemt genvej til en side, du vil kunne finde igen. |
| **Dock** | Ikonlinjen nederst på skrivebordet. |
| **Escape / flugtvej** | En genvej, der kan slippe dig ud af kiosk-tilstanden. |
| **Kiosk** | Fuldskærms-tilstand, hvor browseren fylder hele skærmen. |
| **Netbird / VPN** | En sikker forbindelse, der kører på laptop'en og giver adgang til skolens sider. |
| **Slicer** | Program, der forbereder en 3D-model til 3D-print (fx Bambu Studio). |
| **Vektor** | Tegning lavet af former og linjer, som kan forstørres uendeligt (Inkscape). |

*Det var det! God fornøjelse med din Koderup-laptop. 🦜*
